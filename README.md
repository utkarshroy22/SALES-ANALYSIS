A compelling interactive dashboard for sales performance analysis, customer insights, and regional profitability tracking. Built using Power BI, Power Query, and DAX to transform raw e-commerce data into meaningful business intelligence.

## Overview

This project explores e-commerce sales and customer analytics to uncover:

- Revenue and profit trends over time
- Best-performing regions and categories
- Sales contribution by product and channel
- Customer purchase patterns and basket behavior
- Operational insights that support smarter decision-making

The dashboard is designed for business users who want a quick, visual summary of performance without digging into raw data.

## Why this project?

Modern businesses need more than spreadsheets — they need storytelling through data. This project turns transactional sales data into actionable insights using interactive visuals, filters, and KPI tracking.

It helps answer critical business questions such as:

- Which products generate the highest revenue?
- Which regions contribute most to profit?
- Are sales growing or declining month over month?
- Which categories have the strongest margins?
- Where should marketing and inventory focus next?

## Dataset

This project uses an e-commerce dataset from Kaggle:

- Kaggle dataset: https://www.kaggle.com/datasets/datascikhan/e-commerce-sales-and-customer-analytics?select=order_items.csv

The dataset contains sales transactions and customer-related records that support end-to-end business analysis.

## Getting Started

1. Download the dataset from the Kaggle link above.
2. Load the relevant CSV files into Power BI.
3. Clean and transform the data using Power Query.
4. Build relationships and measures using DAX.
5. Design and customize the dashboard visuals.
6. Share insights with stakeholders.
